Forest Fire FWI Prediction

End-to-End Machine Learning Project

Python | Scikit-learn | Flask

Based on the Algerian Forest Fires Dataset

About This Project

This project demonstrates an end-to-end Machine Learning workflow for estimating the Fire Weather Index (FWI) using historical observations from the Algerian Forest Fires dataset.

The project covers data cleaning, Exploratory Data Analysis (EDA), feature engineering, regression model training, model comparison and evaluation.

Four regression algorithms were explored: Linear Regression, Ridge Regression, Lasso Regression and Elastic Net.

A trained Ridge Regression model, together with StandardScaler preprocessing, was integrated into a Flask web application.

Users can enter weather measurements and fire-index information to receive an estimated FWI value.

Important: This is an educational Machine Learning project for estimating FWI. It is not a real-time wildfire prediction or public safety warning system.

Technologies Used

Python Pandas NumPy Matplotlib Seaborn Scikit-learn Ridge Regression StandardScaler Flask HTML & CSS Jupyter Notebook

Machine Learning Workflow

The project follows the main stages of a supervised Machine Learning workflow.

  1. Data Loading: Import historical Algerian Forest Fires data.
  2. Data Cleaning: Investigate missing values, data types and inconsistent records.
  3. Exploratory Data Analysis: Study distributions, correlations, relationships and outliers.
  4. Feature Engineering: Prepare relevant numerical and categorical model inputs.
  5. Train-Test Split: Separate training data from held-out testing data.
  6. Feature Scaling: Apply StandardScaler using parameters learned from the training data.
  7. Model Training: Train and compare regression algorithms.
  8. Model Evaluation: Evaluate predictions using MAE and R-Squared.
  9. Flask Integration: Connect the saved Ridge Regression model to an interactive web form.

FWI Prediction Application

The Flask web application provides an interface for estimating Fire Weather Index values.

Users can enter the following inputs:

  • Temperature
  • Relative Humidity (RH)
  • Wind Speed (Ws)
  • Rainfall (Rain)
  • Fine Fuel Moisture Code (FFMC)
  • Duff Moisture Code (DMC)
  • Initial Spread Index (ISI)
  • Fire Class (Classes)
  • Region

The application receives user inputs, applies the saved preprocessing scaler, and uses the trained Ridge Regression model to generate an FWI estimate.

Project Objective and Outcome

The objective of this project is to demonstrate practical skills in Machine Learning and application development by building a regression-based FWI estimation system.

The completed application combines dataset preparation, exploratory analysis, regression modelling, evaluation and Flask integration.

This project demonstrates how a trained Machine Learning model can be connected to a web interface to provide predictions from user inputs.

Possible future improvements include more rigorous model validation, automated testing, and deployment to a public hosting platform.
